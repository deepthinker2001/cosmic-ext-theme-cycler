COSMIC Theme Cycler apt repository

A COSMIC panel applet that cycles the desktop theme through the themes you choose, on Pop!_OS 24.04. Source and documentation: github.com/deepthinker2001/cosmic-ext-theme-cycler.

Not an official COSMIC project. This is an independent, community-made applet. It is not made, endorsed, sponsored or supported by System76. COSMIC and Pop!_OS are trademarks of System76, used here only to say which desktop the applet works with.

Install

curl -fsSL https://deepthinker2001.github.io/cosmic-ext-theme-cycler/key.gpg \
  | sudo gpg --dearmor -o /usr/share/keyrings/cosmic-ext-theme-cycler.gpg
echo "deb [signed-by=/usr/share/keyrings/cosmic-ext-theme-cycler.gpg] https://deepthinker2001.github.io/cosmic-ext-theme-cycler stable main" \
  | sudo tee /etc/apt/sources.list.d/cosmic-ext-theme-cycler.list
sudo apt update
sudo apt install cosmic-ext-theme-cycler

Then add Theme Cycler in COSMIC Settings → Desktop → Panel → Configure panel applets. New versions arrive with your normal system updates.
